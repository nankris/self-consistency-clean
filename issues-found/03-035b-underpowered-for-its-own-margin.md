# 03 (035b): Underpowered for its own margin

- **Experiment:** 035b (this repo)
- **Found by:** an independent read-only review of the repo on 21 Oct 2026, 21:13-21:18 IST (fact sheet `035b-self-consistency-clean.md`). Numbers and paths below come from that review, which checked them against the repo's results files.

## Issue and evidence
**Underpowered for its own margin.** CI half-width is about 2.6 pp, so separating 4.6 from 5.0 was never possible. The INCONCLUSIVE outcome was baked in for any true effect between about 2.5 and 7.5 pp. The margin rule (point estimate >= 5) is effectively a coin flip near the true effect.

## Status
Open, documented. Nothing in the results was changed because of it. The README/writeup or the Substack post states where it changes how the result should be read. Any fix needs a new pre-registered run on fresh data (hypothesis rules), not an edit to these numbers.
